# 운영진 계정 발급 구현 계획

작성일: 2026-09-29. 기준: [운영진 계정 발급 스펙](operator-accounts-spec.md)

1. 회원 상태에 `INVITED`를 추가하고 비밀번호가 없는 계정을 허용하는 새 Flyway 마이그레이션을 작성한다. 적용된 V1~V8은 수정하지 않는다.
2. 운영진 계정 생성·목록·재발급 API와 단원의 1회용 비밀번호 설정 API를 만든다. 최초 운영진은 DB 접근 권한이 필요한 별도 명령으로 발급한다.
3. 공개 가입·메일 재설정 경로를 닫고 웹에 운영진 계정 화면과 초대 설정 화면을 연결한다.
4. Compose·E2E·배포 설정에서 SMTP 의존성을 제거하고 운영 절차를 갱신한다.
5. 초대 토큰 사용·재발급·세션 무효화 테스트, 웹 테스트·린트·빌드를 실행한다. Docker 엔진이 준비되면 MySQL 통합 테스트와 브라우저 E2E를 실행한다.

## 현재 검증 상태

- 웹 단위 테스트 44개, 린트, TypeScript 검사, 프로덕션 빌드 통과.
- API 컴파일 및 테스트 컴파일 통과. 새 MySQL 통합 테스트는 Docker 엔진에 연결되지 않아 미실행.
- 메일 없는 Compose 구성과 공개 주소 사전 점검 통과. 브라우저 E2E는 Docker 엔진에 연결되지 않아 미실행.
- 실제 운영 환경, 첫 운영진과 단원 명단, 공개 HTTPS 주소는 아직 미정.
