# 운영 전환 준비 스펙

계정·메일 항목은 당시 설계의 기록입니다. 현재 운영 기준은 [운영진 계정 발급 스펙](operator-accounts-spec.md)과 [운영 절차](operations.md)를 따릅니다.

작성일: 2026-09-29

## 목적

단원 포털을 운영 환경에 공개하기 전에 필요한 설정, 담당자, 검증 증거를 빠짐없이 확인한다. 배포 사업자와 도메인이 아직 정해지지 않았으므로 특정 인프라를 가정한 배포 구성이나 실제 계정 생성은 이 단계에 포함하지 않는다.

## 확인 항목

1. 공개 주소는 유효한 HTTPS 주소이며 이메일 확인 링크의 `VERIFY_BASE_URL`과 출처가 일치한다.
2. DB와 SMTP 비밀값은 저장소 밖에서 공급한다. 점검 결과에는 비밀값을 출력하지 않는다.
3. 실제 배포 경로에서 웹·API 접속, TLS 인증서, 쿠키, 전달 IP와 출석 시도 제한을 확인한다.
4. 운영진은 승인 담당자, 명단 대조 방법, 첫 운영진 이메일을 확정한다. 이메일 확인만으로 단원 자격을 부여하지 않는다.
5. 실제 주소로 인증 메일을 보내고, 별도 환경에서 DB 백업 복구와 기존 출석 조회를 확인한다.
6. 소수 단원으로 가입부터 출석 기록 확인까지 시범 사용한 뒤 공개 범위를 넓힌다.

## 완료 기준

- 사전 점검 도구가 누락 설정, HTTP 주소, 예시 도메인, 서로 다른 서비스 주소를 거부하고 유효한 값은 통과시킨다.
- 실제 운영 전환은 위 항목별 담당자와 확인 결과가 채워진 뒤에만 완료로 표시한다.
- 배포 장소, 실제 도메인, SMTP 계정, 첫 운영진과 명단 대조 절차가 미정인 상태를 완료로 표시하지 않는다.
