# 합창단 용 캐릭터

로고(`web/public/images/choir-mark.png`)의 노래하는 초록 용을 SD 마스코트로 다시 그린 캐릭터다. 로고와는 별개의 그림이고, 로고 원본은 고치지 않는다. 빈 화면처럼 안내 문구만 있으면 허전한 자리에 쓴다.

## 파일과 쓰는 곳

아래 자리에 넣었다. 노래하는 용은 참석으로 응답을 저장한 직후에만 응답 칸 오른쪽에 보인다.

| 파일 | 장면 | 쓰는 곳 |
| --- | --- | --- |
| `web/public/images/dragon-rest.png` | 눈 감고 앉아 쉬는 용 | 홈 '선택한 일정' 칸에서 일정이 없는 날 (예전 calendar 아이콘 자리) |
| `web/public/images/dragon-sing.png` | 입을 벌리고 노래하는 용 | 참석 응답을 마친 뒤 |
| `web/public/images/dragon-search.png` | 돋보기로 악보를 찾는 용 | 없는 페이지(404) |

세 파일 모두 512x512 투명 배경 PNG다. 화면에는 64~240px로 줄여 쓴다. 돋보기 장면은 악보까지 들어가 있어 작게 줄이면 용이 작아 보이니 404처럼 넓은 자리에 쓴다.

## 생김새 규칙

새 장면을 그릴 때는 `docs/images/dragon-model-sheet.jpg`(정면, 비스듬히, 옆, 뒤)를 참고 그림으로 넣고 아래 규칙을 지킨다.

| 부분 | 규칙 |
| --- | --- |
| 체형 | 2등신. 머리가 몸만큼 크고 팔다리는 짧고 통통함 |
| 기본 시점 | 왼쪽으로 비스듬히 돌아선 모습 |
| 눈 | 크고 또렷한 둥근 눈, 진한 초록 눈동자에 작은 반짝임 하나. 졸리거나 심드렁해 보이면 안 됨 |
| 뿔과 갈기 | 가지가 난 뿔 두 개, 머리 뒤를 감싸는 가시 갈기 |
| 날개와 꼬리 | 등에 작고 끝이 뾰족한 날개, 짧은 꼬리 끝은 뾰족하게 |
| 배 | 연한 초록에 가로 줄무늬. 오선처럼 보이게 |

## 색

| 쓰임 | 색 | 사이트 토큰 |
| --- | --- | --- |
| 외곽선, 눈동자 | #004f28 | `--color-primary-hover` |
| 몸 | #008a3e | `--color-brand` (로고 초록) |
| 배 | #dff0e3 | `--color-highlight` |

평면 채색과 굵은 외곽선만 쓰고, 그라데이션과 명암은 넣지 않는다. 노래하는 입속과 돋보기 렌즈에만 다른 색이 조금 들어가 있다.

## 만든 방법

Higgsfield(Nano Banana Pro)에서 로고를 참고 그림으로 넣어 기준 그림을 만들고, 그 기준 그림을 다시 참고로 넣어 장면을 뽑았다. 흰 배경을 지우고 512px로 줄여 저장했다.
