# 구글 로그인과 단원 승인 스펙

작성일: 2026-09-30. 이 문서는 계정 인증에 관한 기존 운영진 계정 발급 스펙보다 우선합니다.

## 사용자 흐름

1. 방문자는 공개 홈페이지를 이용하고, 회원 영역에 들어가려면 구글 계정으로 로그인합니다. 이메일·비밀번호 로그인과 공개 비밀번호 설정은 제공하지 않습니다.
2. 서버는 구글 ID 토큰의 서명, 발급자, 수신 대상, 만료, 이메일 확인 여부를 검증합니다. 회원 계정은 이메일이 아닌 구글의 고유 식별값 `sub`로 연결합니다.
3. 처음 로그인한 계정의 확인된 이메일이 화이트리스트에 정확히 일치하고 구글이 현재 해당 주소의 소유를 보증하는 경우, 화이트리스트에 지정된 활동 단원 또는 OB로 자동 승인합니다.
4. 명단에 없거나 구글이 현재 이메일 소유를 보증하지 않는 경우에는 승인 대기로 등록합니다. 대기자와 반려자는 본인 상태만 확인하고 회원 공지·행사·투표·출석에는 접근하지 못합니다.
5. 운영진은 대기자의 신원을 명단과 대조해 활동 단원 또는 OB로 승인하거나 반려합니다. 승인 후에는 같은 구글 계정으로 다시 로그인할 때 별도 승인이 필요하지 않습니다.
6. 접근 해제된 계정은 구글 인증에 성공해도 재승인되지 않으며 기존 세션도 사용할 수 없습니다. 화이트리스트에서 이메일을 지우는 동작은 기존 회원의 접근 해제를 대신하지 않습니다.

## 화이트리스트와 계정 연결

- 화이트리스트에는 정규화한 이메일, 단원 구분, 선택적인 표시 이름, 등록 운영진과 등록 시각을 저장합니다. 운영진만 등록·조회·삭제할 수 있으며 운영진 권한을 자동 부여하지 않습니다.
- 구글이 주소를 보증하는 경우는 `@gmail.com` 계정 또는 ID 토큰의 `hd`가 이메일 도메인과 일치하는 관리형 계정입니다. 그 외 주소는 `email_verified`가 참이어도 수동 승인으로 보냅니다.
- 대기 중 화이트리스트에 추가된 계정은 **다음 구글 로그인**에서 자동 승인됩니다. 반려·접근 해제는 화이트리스트보다 우선합니다.
- 이미 이메일이 등록됐지만 구글 고유 식별값이 연결되지 않은 기존 계정은 이메일만으로 자동 연결하지 않습니다. 운영진이 발급한 1회용 계정 연결 링크와 같은 구글 계정을 함께 확인한 뒤 연결합니다.
- 최초 운영진은 DB 접근 권한이 필요한 기존 비공개 초기화 명령으로 초대합니다. 1회용 링크와 구글 계정을 함께 확인해 계정을 연결합니다. 공개 가입이나 화이트리스트로 운영진 권한을 얻을 수 없습니다.
- 구글 계정의 이메일이 변경되어도 기존 `sub`와 회원 상태는 유지합니다. 이메일 변경과 단원 구분 변경은 운영진이 확인합니다.

## 보안과 검증

- 구글 토큰 검증은 서버에서 수행하며 위조·만료·잘못된 수신 대상·미확인 이메일을 거부합니다. 로그인 요청마다 서버가 일회용 `nonce`를 발급하고 ID 토큰의 값과 대조해 재사용을 막습니다. 민감한 토큰과 초대 링크 원문을 로그에 남기지 않습니다.
- 기존 CSRF 보호, `HttpOnly`·`Secure`·`SameSite=Lax` 세션 쿠키, 로그인 세션 ID 교체, 요청마다 회원 상태·`authVersion` 재검사를 유지합니다.
- 운영진의 수동 승인·반려·접근 해제와 화이트리스트 변경을 기록합니다. 화이트리스트 자동 승인도 근거가 된 등록 운영진과 함께 기록합니다.
- 승인 대기·반려·접근 해제 계정이 회원 API를 사용할 수 없는지, 활동 단원과 OB의 출석 대상 구분이 유지되는지 검증합니다.
- 실제 구글 로그인은 Google Cloud 웹 클라이언트 ID, 승인된 사이트 출처, 배포 환경 변수가 설정된 뒤 HTTPS 주소에서 검증합니다. 그 전에는 배포 완료로 표시하지 않습니다.
