# 용어 사전

화면 이름, 버튼, 안내 문구는 이 표의 말을 씁니다. 어느 서비스에나 붙는 말(계정, 목록, 접근) 대신 합창단에서 쓰는 말을 고릅니다. 코드 이름과 경로는 바꾸지 않습니다. 2026-11-03 정리.

| 화면 이름 | 뜻 | 쓰이는 곳 | 코드 |
| --- | --- | --- | --- |
| 단원 | 포털을 쓰는 사람. 회원이라고 쓰지 않는다 | 모든 화면 | `Member` |
| 활동 단원, OB | 단원 구분. 직책은 활동 단원만 가진다 | 단원 정보 관리, 가입 승인 | `MemberType` ACTIVE, OB |
| 기수, 파트 | 입단 기수와 소프라노, 알토, 테너, 베이스, 피아노 | 단원 정보, 가입 신청 | `cohort`, `Part` |
| 직책 | 단장, 부단장, 총무, 부장, 부원, 수석 | 단원 정보 수정 | `Role` |
| 운영진 | 회의록 보기 말고 다른 권한이 하나라도 있는 단원 | 상단 메뉴 | `isStaff` |
| 사이트 관리자 | 모든 권한을 가진 단원 | 단원 정보 관리 | `admin` |
| 가입 신청 | 등록 없이 구글 계정으로 로그인해 승인을 기다리는 일 | 가입 승인, 가입 승인 알림 띠 | `APPROVAL_PENDING` |
| 승인, 반려, 반려 취소 | 가입 신청을 처리하는 세 동작 | 가입 승인, 단원 정보 관리 | `approve`, `reject`, `cancelRejection` |
| 사전 등록 | 명단에 있는 새 단원의 Gmail을 미리 등록해 첫 로그인에 바로 승인되게 하는 일 | 단원 정보 관리 | 자동 승인 명단 `MemberAllowlist` |
| 사이트 관리자 권한도 부여 | 사전 등록하면서 첫 로그인에 사이트 관리자 권한까지 주는 선택 | 사전 등록 폼 | 운영진 사전 등록 `OperatorPreapproval` |
| 사전 등록된 단원 | 등록만 되고 아직 로그인하지 않은 사람 | 단원 정보 관리 | `/admin/allowlist`, `/admin/operator-preapprovals` |
| 1회용 링크로 초대 | Gmail이 아닌 주소에 계정을 만들고 연결 링크를 한 번 발급하는 일 | 단원 정보 관리 | `invitations`, `INVITED` |
| 단원 명단 | 모든 단원과 계정 상태의 목록 | 단원 정보 관리 | `GET /admin/members` |
| 단원 정보 관리 | 단원 명단을 보고 파트, 기수, 직책을 고치는 운영진 화면 | 하위 메뉴 | `/admin/members` |
| 단원 정보 수정 | 한 단원의 구분, 파트, 기수, 직책을 고치는 펼침 | 단원 정보 관리 | `MemberRoles` |
| 포털 이용 중단 | 단원이 포털을 더 쓰지 못하게 하는 일. 직책이 모두 지워지고 다시 초대해야 쓸 수 있다. 상태는 "이용 중단" | 단원 정보 관리 | `REVOKE_ACCESS`, `REVOKED` |
| 일정 | 정기연습, 비정기연습, 파트연습, 중요 행사 네 종류 | 홈, 일정 관리 | `ScheduleKind` |
| 참석 응답 | 일정에 미리 밝히는 참석, 불참 | 홈, 일정 관리 | `rsvp` |
| 출석, 지각, 미출석 | 현장 출석 창에서 남는 기록. 출석 대상 아님은 따로 | 현장 출석, 출석 관리 | `attendance` |
| 정정 | 운영진이 이유를 적어 출석 기록을 바꾸는 일 | 출석 관리 | `correction` |
| 공지, 초안, 게시 | 운영진이 쓰는 글. 초안은 단원에게 안 보이고 게시해야 보인다 | 공지, 공지 관리 | `Notice.published` |
| 투표 | 공지에 하나 붙이는 두 선택지 설문 | 공지 | `NoticePoll` |

## 쓰지 않는 말

| 쓰지 않는 말 | 대신 쓰는 말 |
| --- | --- |
| 회원 | 단원 |
| 행사(일정 전체를 가리킬 때) | 일정. 중요 행사는 일정의 한 종류 |
| 단원 계정 | 단원 정보 관리 |
| 계정 목록 | 단원 명단 |
| 미리 승인, 미리 승인한 이메일 | 사전 등록, 사전 등록된 단원 |
| 접근 해제 | 포털 이용 중단 |
